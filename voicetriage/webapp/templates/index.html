How to Use VoiceTriage

1
Speak or Type
Use the Speak tab to speak patient symptoms live, or switch to Text to type/paste. Use Demo for pre-built cases.
2
Select Language
Choose the language of the input so the system can correctly process regional terms (Hindi, Tamil, etc.).
3
Click Analyze / Run Triage
The AI runs all 4 pipeline stages: Speech → NLP → RAG → Decision. Takes ~1–5 seconds.
4
Read the Result
Dashboard shows urgency (🔴 Emergency / 🟡 Urgent / 🟢 Routine), specialist, confidence score, extracted symptoms, and a plain-language reason.
5
Use the Decision
Hand the result to the call-centre operator. The AI assists — the doctor always makes the final call.
6
View History & Stats
Click History to see all previous triages. Click Stats for urgency distribution and confidence metrics.
⚕️ Scope: This tool is for pre-call triage routing only. It does not diagnose or prescribe treatment.
